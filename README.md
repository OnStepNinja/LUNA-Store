# LUNA Store

The community place for **LUNA Store** — the store inside **LUNA Base** on your ESP32 board.
Ask questions, share what you built, and send ideas in **[Discussions](https://github.com/OnStepNinja/LUNA-Store/discussions)**.

LUNA Base(ESP32 の基板の中の LUNA Store)を使う皆さんの交流の場です。
質問・作例・要望は **[Discussions](https://github.com/OnStepNinja/LUNA-Store/discussions)** へどうぞ。日本語で書き込めます。

## What to post / 書き込む内容

| Category | Use it for |
|---|---|
| Announcements / お知らせ | News from the developer (read only) / 開発者からのお知らせ(読むだけ) |
| Q&A / 質問 | Questions about the boards and firmware in LUNA Store / Store の基板・ファームの質問 |
| Show and tell / 作例 | What you built or observed / 作ったもの・観測の報告 |
| Ideas / 要望 | Requests and ideas / 要望・アイデア |
| General / 雑談 | Anything else, any language / そのほか(日本語・英語どちらでも) |

Use 👍 on posts you like. / 良いと思った投稿には 👍 を付けてください。

## Please / お願い

- **Never post passwords, Wi-Fi settings (SSID/password) or your home IP address.** Logs and screenshots can contain them — check before posting.
- **パスワード・Wi-Fi の設定(SSID・パスワード)・家の IP アドレスは書かないでください。** ログや画面の写真に入っていることがあります。投稿の前に確かめてください。
- Tell us the board, firmware name and version (for example: *OnStepNinja NS-4000 1.2.8*, *LUNA Base 0.9.1*).
- 質問には、基板・ファームの名前と版を書いてください(例: *OnStepNinja NS-4000 1.2.8*、*LUNA Base 0.9.1*)。
- Be kind. Posts that break the rules may be removed. / 思いやりのある書き込みを。ルールに合わない投稿は消すことがあります。
