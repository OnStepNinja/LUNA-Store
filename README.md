# LUNA Store

The community place for **LUNA Store** — the store inside **LUNA Base** on your ESP32 board.
Ask questions and send ideas in **[Discussions](https://github.com/OnStepNinja/LUNA-Store/discussions)**.

## Categories

| Category | Use it for |
|---|---|
| Announcements | News from the developer (read only) |
| Q&A | Questions about LUNA Store, its boards and firmware |
| Ideas | Requests, ideas and feedback |

Please write in English if you can. (日本語でも構いません。)

Use 👍 on posts you like.

## Please

- **Never post passwords, Wi-Fi settings (SSID/password) or your home IP address.** Logs and screenshots can contain them — check before posting.
- Tell us the board, firmware name and version (for example: *OnStepNinja NS-4000 1.2.8*, *LUNA Base 0.9.1*).
- Be kind. Posts that break the rules may be removed.

## Products in LUNA Store
